# 一体化工作台

轻量级本地工作台，提供网页搜索入口、Gmail/Outlook 快捷访问、快速撰写邮件、本地网址格式检查和可扩展工具箱。

## 运行

需要 Node.js 18 或更高版本；无需安装第三方依赖。

```sh
npm start
```

默认只监听 `127.0.0.1:3000`。打开 http://127.0.0.1:3000 即可使用。可通过 `PORT` 和 `HOST` 环境变量调整监听设置，例如：

```sh
PORT=8080 npm start
```

运行测试：

```sh
npm test
```

## 扩展工具

在 `app.js` 注册经过审核的工具：

```js
window.toolbox.registerTool({
  id: "my-tool",
  name: "我的工具",
  description: "工具用途说明",
  category: "扩展工具",
  action: () => {
    // 在这里实现受信任的工具行为
  },
});
```

工具通过 DOM 文本接口展示，不会将描述当作 HTML 执行。不要从不可信来源动态载入代码。

## 能力范围

- 搜索会在新标签页打开所选的第三方搜索引擎。
- 邮箱快捷入口打开 Gmail 或 Outlook 网站；快速撰写使用设备的默认邮件应用。此项目不连接邮箱账号，也不读取或存储邮件。
- 网址检查只在浏览器本地检查格式和少量明显信号，不会访问网址，也不是恶意软件或信誉扫描器。
- `/api/health` 提供本地服务健康状态；`/api/tools` 列出内置工具。

此版本不包含在线扫描引擎、邮箱 API/OAuth、账号管理或远程安装器。部署到公网前应使用 HTTPS，并配置适当的认证、反向代理和安全策略。
